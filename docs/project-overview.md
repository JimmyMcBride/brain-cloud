## Local Notes

Brain Cloud is the API-first hosted and self-hostable platform for Brain Core and optional official/community modules. Planning is an optional official module, not a separate cloud platform; Hive Mind remains Core. Phase 0 implements compatibility discovery and operational endpoints only. Product scope and current limitations are in `README.md`; full direction is in `docs/product-vision.md` and `docs/roadmap.md`.
